# Security Policy

## Intended use

This project is a security **testing** tool meant for authorized assessments, learning,
and defensive research. Use it only against systems you own or are explicitly permitted
to test.

## Reporting a vulnerability in this tool

If you discover a security issue in the scanner itself (for example, a way it could be
abused to harm a third party, or a dependency vulnerability), please open a private
report via GitHub Security Advisories on this repository, or open an issue describing the
problem without including working exploit details.

Please do **not** use this project to attack systems without authorization. Doing so may
violate the Computer Fraud and Abuse Act (US), the Computer Misuse Act (UK), or equivalent
laws in your country.
